# Landing Page - FitStudio 🏋️‍♂️

Segundo projeto de treino focado em solidificar os fundamentos de HTML semântico e CSS Flexbox antes das avaliações do The Odin Project.

## 🎯 Objetivo

Criar a estrutura visual de um estúdio de personal training, aplicando a memória muscular nos comandos de alinhamento com Flexbox.

## 🛠 Tecnologias e Conceitos Aplicados

- **HTML5:** Tags semânticas (`header`, `main`, `section`, `footer`).
- **CSS3 & Flexbox:**
  - Uso de `flex: 1` para criar colunas iguais na secção Hero.
  - Uso de `flex-wrap: wrap` e `gap` para organizar cartões de treino.
  - Uso de `align-self: flex-end` para posicionamento individual na secção de citações.
